How it works

Two loops. One graph.

A question becomes a fixed query. A change event rewrites ownership without deleting it.

Ask

From question to answer

1

Question

“Who owns payments-api?” The model sees five tool schemas. It never sees the data.

2

Tool

It picks one tool and fills in a name or a date. If it fails, a keyword router picks.

3

Cypher

A fixed, parameterised template runs on FalkorDB. The model writes no Cypher.

4

Answer

A short answer with the path it used and the messages that prove it.

Hand over

When someone moves on

1

Event

“Tunde left, Ada takes over.” Text becomes one fixed JSON shape. Anything else is rejected.

2

Close and open

Old ownership gets an end date. New ownership opens. Nothing is deleted.

3

Move tickets

Open tickets follow the new owner, each with a reason and a source.

4

Look back

“Who owned it on 2026-09-01?” still answers, because the history stayed.
